ReCell

Used Device Price Prediction using Machine Learning

Project Overview

This project predicts the prices of used phones and tablets using Linear Regression and detailed data analysis. The dataset includes device features like brand, RAM, memory, camera, battery, and usage history.

Python Machine Learning Linear Regression Data Analysis Pandas & NumPy Scikit-learn

Key Highlights

  • Exploratory Data Analysis (EDA)

    Analyzed device pricing trends and patterns

  • Data Preprocessing

    Handled missing values and feature engineering

  • Linear Regression Model

    Built predictive model for normalized prices

  • Key Factor Identification

    Identified factors affecting device prices

  • Model Evaluation

    Evaluated using RMSE, MAE, R² metrics

  • Data Visualization

    Created insightful charts and graphs
