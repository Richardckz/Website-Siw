AfroRecipes

Piattaforma web per la scoperta, condivisione e gestione di ricette africane autentiche

Stack Tecnologico

Backend

Java 21 LTS Spring Boot 3.3.6 Spring Data JPA Spring Security 6 Spring OAuth2 Client Thymeleaf Jakarta EE

Database

H2 (Sviluppo) PostgreSQL (Produzione)

Frontend

HTML5 CSS3 JavaScript

Build & Deployment

Maven 3.8+ Spring Boot Maven Plugin

Funzionalità

Autenticazione

  • Registrazione e login con credenziali locali
  • Login sociale via OAuth2 (Google, GitHub)
  • Gestione ruoli: USER, ADMIN
  • Sistema di ban utenti

Gestione Ricette

  • CRUD completo ricette
  • Categorie: Colazione, Pranzo, Cena, Snack, Bevande, Dolci
  • Livelli difficoltà: Facile, Medio, Difficile
  • Tempo di preparazione
  • Upload immagini
  • Gestione ingredienti con unità di misura

Sistema Recensioni

  • Valutazione 1-5 stelle
  • Commenti testuali
  • Timestamp automatico
  • Calcolo rating medio automatico

Amministrazione

  • Dashboard admin con statistiche
  • Gestione utenti (visualizzazione, ban)
  • Controllo contenuti

Installazione

# Clona il repository
git clone https://github.com/Richardckz/AfroRecipes.git
cd AfroRecipes

# Build del progetto
./mvnw clean package

# Avvio applicazione
./mvnw spring-boot:run

L'applicazione sarà disponibile su: http://localhost:8080

Credenziali Default

Ruolo Email Password
ADMIN admin@example.com admin123
USER user@example.com user123

Variabili d'Ambiente (Produzione)

# OAuth2 Google
GOOGLE_CLIENT_ID=your-google-client-id
GOOGLE_CLIENT_SECRET=your-google-client-secret

# OAuth2 GitHub
GITHUB_CLIENT_ID=your-github-client-id
GITHUB_CLIENT_SECRET=your-github-client-secret

# Database PostgreSQL
SPRING_DATASOURCE_URL=jdbc:postgresql://localhost:5432/afrorecipes
SPRING_DATASOURCE_USERNAME=postgres
SPRING_DATASOURCE_PASSWORD=your-password
SPRING_JPA_HIBERNATE_DDL_AUTO=update

Database

Sviluppo

H2 configurato automaticamente

Dati persistono in ./data/afroRecipes.mv.db

Produzione

Modificare application.properties per PostgreSQL

Modello di Dominio

User

  • id: Long (PK)
  • name, surname: String
  • email: String (UNIQUE)
  • password: String (hashed)
  • role: String (USER | ADMIN)
  • banned: boolean
  • oauthProvider: String (LOCAL | GOOGLE | GITHUB)

Recipe

  • id: Long (PK)
  • title: String
  • shortDescription: String
  • procedure: String
  • preparationTime: Integer
  • difficulty: EASY | MEDIUM | HARD
  • category: String
  • author: User (N:1)
  • ingredients: List
  • reviews: List

Ingredient

  • id: Long (PK)
  • name: String
  • quantity: BigDecimal
  • unit: MeasurementUnit
  • recipe: Recipe (N:1)

Review

  • id: Long (PK)
  • text: String
  • rating: Integer (1-5)
  • createdAt: LocalDateTime
  • recipe: Recipe (N:1)
  • author: User (N:1)

Endpoint API

Autenticazione

Metodo Endpoint Descrizione
GET /auth/login Pagina login
POST /auth/register Registrazione
GET /auth/logout Logout

Ricette

Metodo Endpoint Descrizione
GET /recipes Lista ricette pubbliche
GET /recipes/{id} Dettaglio ricetta
POST /recipes Crea ricetta
PUT /recipes/{id} Modifica ricetta
DELETE /recipes/{id} Elimina ricetta

Admin

Metodo Endpoint Descrizione
GET /admin/dashboard Dashboard admin
GET /admin/users Lista utenti
POST /admin/users/{id}/ban Ban utente
