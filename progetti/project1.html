ReCell – Used Device Price Prediction

Project Overview

This project predicts the prices of used phones and tablets using Linear Regression and detailed data analysis. The dataset includes device features like brand, RAM, memory, camera, battery, and usage history.

Key Highlights

  • Performed Exploratory Data Analysis (EDA) to understand device pricing trends.
  • Preprocessed data including handling missing values and feature engineering.
  • Built a Linear Regression model to predict normalized used device prices.
  • Identified key factors affecting device prices (RAM, memory, camera, brand).
  • Evaluated model performance using RMSE, MAE, R² metrics.
